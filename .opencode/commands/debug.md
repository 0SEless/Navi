## Workflow: Debug / Fix Bug

### Step 1 — Diagnose
Load `diagnosing-bugs`. Systematically trace the issue — reproduce, isolate root cause, check assumptions.

### Step 2 — Security Check
Load `ponytail-audit`. Review the fix for security implications. Check for injection, auth bypass, data leaks.
