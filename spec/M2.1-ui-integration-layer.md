# M2.1 — UI Integration Layer

## What

Build the thin integration layer that connects the EditorService framework to React UI components, establishing a single source of truth for selection state and a clean projection layer for the Explorer tree.

**No visual changes.** No new React components (Explorer, Inspector, Toolbar, Canvas). Only infrastructure that UI components consume.

```
                      ┌─────────────┐
                      │CampusDocument│
                      └──────┬──────┘
                             │
                ┌────────────▼────────────┐
                │    ExplorerAdapter      │
                │  (CampusDoc → Node[])   │
                └────────────┬────────────┘
                             │
                ┌────────────▼────────────┐
                │   SelectionManager      │
                │  (mode, origin, hover)  │
                └────────────┬────────────┘
                             │
                      selection.changed
                             │
                ┌────────────▼────────────┐
                │    SelectionStore        │
                │  (React reactive hook)  │
                └────────────┬────────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
         Explorer       Inspector      Canvas
              │              │              │
              └──────────────┼──────────────┘
                             │
                ┌────────────▼────────────┐
                │   Legacy Zustand        │◄── SelectionBridge
                └─────────────────────────┘
```

## Success Criteria

1. **EntityId branded type** replaces raw `string` for entity identity across the editor's public API
2. **SelectionManager** supports `selectionMode` (single/multi/marquee) and tracks `origin` (canvas/explorer/inspector/keyboard)
3. **SelectionStore** is a React hook (`useSelection()`) that subscribes to `selection.changed` events — no component reads SelectionManager directly
4. **ExplorerAdapter** converts `CampusDocument` → `ExplorerNode[]` — pure transformation, no React, no state
5. **SelectionBridge** synchronizes legacy Zustand stores (`useStudioStore`, `useGraphStore`) through SelectionManager so old and new components coexist
6. **WorkspaceContext** derives active workspace (campus/building/floor/validation) from selection state
7. **430 existing tests still pass** — no regressions in existing behavior
8. Observable: selecting in canvas updates Explorer/Inspector, selecting in Explorer updates canvas, keyboard navigation consistent

## Known Pitfalls

- Branded types are TypeScript-only — string comparisons still work, but accidental mixing is caught at compile time
- SelectionStore must batch React re-renders during transactions (EventBus already supports this)
- SelectionBridge needs careful two-way sync to avoid update loops (track origin to prevent echo)
- WorkspaceContext should be derived, not stored — don't add more state that can drift
