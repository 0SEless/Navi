## Workflow: Refactor / Tech Debt

### Step 1 — Identify Debt
Load `ponytail-debt`. Scan for tech debt patterns — dead code, TODO sprawl, duplicated logic, god objects.

Load `ponytail-gain`. Find the highest-impact, lowest-effort improvements. Prioritize.

### Step 3 — Architecture Improvement
Load `improve-codebase-architecture`. For larger structural changes, apply appropriate patterns.
