# Floor route workflow - approved design 2026-11-13

User approved free route drawing, optional independent entrance outdoor connections, intentional junctions in one floor network, explicit stair/elevator floor access, and a floor-wide Suggest Connections review for doors/entrances/stair landings/elevator stops. Suggestions are temporary, draggable/correctable, individually excluded, Confirm applies one undoable batch, Cancel changes nothing; confirmed connections remain editable/disconnectable. No guessed wall-crossing connections, existing links preserved by default. Outdoor and vertical links remain distinct.

Implementation approach: retain existing document format where possible. An entrance can own a real floor-side terminal route node at its physical location without any indoor path edges; outdoor-only connection does not fabricate an indoor route line. Explicit route ports and access edges will join floor backbone routes; compiler must honor explicit feature ports instead of nearest fallback. Free path starts anywhere; ending on an entrance completes the path without forcing another outdoor pick. Outdoor picker confirms just one explicit outdoor attachment and returns to Select. Point-on-segment picks project to the centerline. Intentional joins reuse/split existing nodes/segments. Per-floor review must revalidate current geometry before commit, preserve existing links, and undo exact snapshots.

Constraints: existing feat/save-v2 worktree only; preserve all prior uncommitted work; no staging/commits/Save/Done/Publish/map DB writes/user tab or lock access; never read/copy env import file; one existing localhost3001 only; tests512MB serial worker. Limited user quota: maintain emergency handoff and stop safely if user reports1 percent. Agent cannot read account usage percentage, must never invent it.
