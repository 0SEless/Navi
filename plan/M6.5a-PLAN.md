# M6.5a — Panorama Package Extension — PLAN

## Approach

Add a new **optional** `panoramaIndex` artifact across the four pipeline packages. Extends (does not modify) the frozen pipeline. No runtime capability yet — that is M6.5b.

## Error prevention (relevant ERRORS.md entries)

- None recorded for pipeline extensions. Preventing: silent artifact skip if publisher `ARTIFACT_NAMES` / loader registry / converter / validator are not all updated together. Mitigation: T5 tests assert the artifact is written, loaded, and non-undefined end-to-end.

## Tasks

### T1 — Core types (`@navi/core`)
**Files:** `packages/core/src/types/navigation-artifacts.ts`, `packages/core/src/types/package-format.ts`
- Add `HotspotEntry`, `PanoramaEntry`, `PanoramaIndex` to `navigation-artifacts.ts`.
- Add `panoramaIndex?: PanoramaIndex` to `NavigationArtifacts`.
- Add `HotspotFile`, `PanoramaEntryFile`, `PanoramaIndexFile` to `package-format.ts`.
- **Acceptance:** types compile; no existing type changed.

### T2 — Compiler emits `panoramaIndex`
**Files:** `packages/compiler/src/emitter/artifacts.ts`, `packages/compiler/src/pipeline/campus-compiler.ts`
- `buildArtifacts(connectivityGraph, navGraph, document)` — add `panoramaIndex` built from `document.panoramas` (pass-through + hotspot normalization, sorted by id).
- Update `campus-compiler.ts` line 165 to pass `document`.
- **Acceptance:** compile a doc with panoramas → `artifacts.panoramaIndex.panoramas.length === document.panoramas.length`; ids/hotspots preserved; deterministic.

### T3 — Publisher writes `panorama` artifact
**Files:** `packages/publisher/src/package-builder.ts`, `packages/publisher/src/types.ts`, `packages/publisher/src/index.ts`, `packages/publisher/src/publisher.ts`
- Add `buildPanoramaFile()` + `panorama?` to `BuiltPackage` + `schemaVersions.panorama`.
- Add `'panorama'` to `ARTIFACT_NAMES` in `publisher.ts`.
- Re-export new file types from `types.ts` + `index.ts`.
- **Acceptance:** publish writes `panorama.json`; manifest includes `panorama` entry; older packages (no panorama) unchanged.

### T4 — Loader hydrates `panoramaIndex`
**Files:** `packages/runtime/src/loader/types.ts`, `packages/runtime/src/loader/package-loader.ts`, `packages/runtime/src/loader/runtime-converter.ts`
- Add `panoramaIndex?` to `LoadedPackage`.
- Add `panoramaValidator`, `toRuntimePanorama`, registry entry `'panorama'`, and attach to `LoadedPackage`.
- **Acceptance:** package with panorama → `loaded.panoramaIndex` defined; package without → `undefined`; no regression to other artifacts.

### T5 — Tests + full verification
**Files:** new tests under each package's `__tests__`
- compiler: emits panoramaIndex (count, ids, hotspots, determinism).
- publisher: writes panorama artifact + manifest entry; omits when absent.
- runtime loader: hydrates panoramaIndex; graceful when absent.
- Run full workspace test suite. **Acceptance:** all existing tests pass + new tests pass.

## Checkpoints

- After T1: `tsc` clean in core.
- After T2: compiler unit test green.
- After T3: publisher test green; manifest contains panorama.
- After T4: loader test green.
- After T5: full suite green (target: ~185+ tests).

## Notes

- No `PanoramaService` here. M6.5b consumes `LoadedPackage.panoramaIndex`.
- Frozen layers respected: only additive optional artifacts/fields.
