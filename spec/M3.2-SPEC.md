# M3.2 — CampusDocument as Source of Truth

## What

Replace `useGraphStore` with `CampusDocument` + `CommandDispatcher` as the single source of truth **inside the editor** (`EditorProvider` tree). After M3.2, no editor component reads `Graph` directly or mutates it through legacy graph-store methods.

## Scope

**In scope** — all components inside `<EditorProvider>`:
- Catalog reads (MapRenderer, FloorTabs)
- Existing EditorProvider consumers (Explorer — already done)
- Write-path tools (ConfirmOverlay, useVertexEditor, useEntrancePlacer, CreateMapWizard, InteractionController)
- FloorEditor subsystem (FloorEditorCanvas, useFloorDrawing, FloorOutliner, ComponentProperties)

**Out of scope** — public-facing and runtime consumers:
- CampusMap, PublicMap, SearchBar, BuildingInfo
- Runtime navigation pages
- `_archive/` directory
- Legacy panel deletion (post-M3.2 cleanup)

## Success Criteria

1. No editor component imports `useGraphStore` for reads — all reads go through `DocumentStore` / `useDocument()` / selectors
2. No editor component calls `useGraphStore` write methods — all writes dispatch commands through `CommandDispatcher`
3. `Graph` still exists but is only consumed by the Navigation Compiler for runtime routing
4. All existing tests pass without modification
5. Build succeeds

## Waves

| Wave | Goal | Components |
|------|------|-----------|
| M3.2.1 | Document Read Model | Document selectors, MapRenderer, FloorTabs, Inspector |
| M3.2.2 | Document Write Model | InteractionController, ConfirmOverlay, useVertexEditor, useEntrancePlacer |
| M3.2.3 | Ownership Audit | Verify no editor `useGraphStore` usage remains |
| M3.2.4 | FloorEditor Migration | FloorEditorCanvas, useFloorDrawing, FloorOutliner, ComponentProperties |

### Reclassification Note

**CreateMapWizard is excluded from M3.2 scope by ADR 0014.** It is an Application Bootstrap Workflow that runs before `EditorContext` exists. See `docs/decisions/ADR-0014-application-bootstrap-workflow.md` for rationale. Shared components extracted from it (e.g., `BuildingMetadataForm`) live in `src/components/shared/`.

## Pitfalls

- FloorEditor is the highest-risk subsystem — do it last after all infrastructure is stable
- `GraphAdapter` must remain bidirectional for the Navigation Compiler path
- Do not delete `graph-store.ts` yet — public/runtime pages still depend on it
- CreateMapWizard remains on graph-store by design (see ADR 0014)
