## Tasks

### T1. Create SearchService

New class in `packages/runtime/src/engine/search-service.ts`. Wraps `SearchEngine`. Methods: `search`, `autocomplete`, `findById`, `findByCategory`. Returns domain `SearchResult` (readonly) via private `mapEntry()` helper. `SearchCategory` derives from `SearchEntry['type']`.

**Files to create:** `packages/runtime/src/engine/search-service.ts`

**Acceptance:** `SearchService` constructed from `LoadedPackage`, exposes all 4 methods, `search()` delegates to `SearchEngine`, `findById()` returns `SearchResult | undefined`, all methods handle `undefined` searchIndex gracefully.

---

### T2. Create domain SearchResult type

Define `SearchResult` interface and `SearchCategory` type in the new `search-service.ts`. Readonly fields: `id`, `title`, `category`, `nodeId`, `score?`, `buildingId?`, `floor?`. `score` is optional — only `search()` and `autocomplete()` populate it.

**Acceptance:** `SearchResult` is a readonly domain type. `SearchCategory = SearchEntry['type']`. `mapEntry()` converts `SearchEntry` to `SearchResult`.

---

### T3. Replace SearchAPI with SearchService in RuntimeEngine

Remove `SearchAPI` import and instantiation. Import and construct `SearchService` from `LoadedPackage` instead. `search` property type changes from `SearchAPI` to `SearchService`.

**Files to touch:** `packages/runtime/src/engine/runtime-engine.ts`, `packages/runtime/src/engine/index.ts`, `packages/runtime/src/index.ts`

**Files to delete:** `packages/runtime/src/engine/search-api.ts`
