## Workflow: Implement / Build

### Step 1 — Prototype
Load `prototype`. Build a working version quickly. Focus on the core flow, skip edge cases initially.

### Step 2 — Test
Load `tdd`. Write tests for the prototype. Red-green-refactor cycle.

### Step 3 — Simplify
Load `ponytail`. Run the lazy ladder — cut any bloat, use stdlib, one-liner where possible.
