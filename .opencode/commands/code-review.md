## Workflow: Code Review

### Step 1 — Lazy Review
Load `ponytail-review`. Review the code with a focus on simplicity, YAGNI, and minimalism. Identify what's over-engineered.

### Step 2 — Bug Diagnosis
Load `diagnosing-bugs`. Systematically check for edge cases, error handling, and logic flaws.

### Step 3 — Final Pass
Load `ponytail`. Apply the lazy ladder — is there a simpler way? Any unnecessary abstractions?
