# P1.2 Seam 2 — Stage A: Capability Ownership Matrix

**Rule (ADR 006 Interaction Ownership Rule):** every editor interaction is owned by
exactly one `ToolRegistry` tool. `InteractionController` is an event router only.

**Gate:** `InteractionController` may be deleted only after every row below has a
*verified* new owner AND its legacy handler is removed. Deletion is the last step.

Verified = a registered `ToolRegistry` tool (or dedicated render component) exists
that handles the same event/class of interaction.

## Gaps (must each get a verified owner before any deletion)

> **Decisions (2026-07-15):**
> - **G1 + G7 → PLANNED REMOVAL** (Road Authoring Rule). Compiled traces are
>   compiler output, not an editable model. The only authored path entity is
>   `Road`. Remove compiled-trace selection (`setSelectedTraceId`) and the legacy
>   `route`/trace editing; canvas clicks resolve to `Road` via provenance.
> - **G9 → migrate `ComponentPalette` to `ToolRegistry.activate`** (Tool Activation
>   Rule). `setTool` becomes a thin adapter; once the palette is on the registry the
>   legacy `switch(tool)` fallback becomes unreachable and is removed.

- **G1** Compiled-trace selection — **DECIDED: remove** (Road Authoring Rule). Resolve to `Road` via provenance. No tool needed.
- **G2** "Set active building" on building click (`setActiveBuilding`) — `selectTool` selects entity but not the editing context.
- **G3** Draw Room via **drag rectangle** — `drawRoomTool` is vertex-only; legacy path reachable via `ComponentPalette` `room`.
- **G4** Keyboard **Delete** — no ToolRegistry delete tool exists.
- **G5** Vertex drag of **in-progress** draw/trace points — `useVertexEditor` only edits existing geometry.
- **G6** Drawing **preview** for the active registry draw/place tool — controller's `updateDrawPreview` still drives it.
- **G7** Legacy `route` / **compiled-trace editing** — **DECIDED: remove** (Road Authoring Rule). `route` tool → `draw-road` only.
- **G8** Generic **asset** click-add — `place-*` covers specific types; generic `asset` branch has no tool.
- **G9** Legacy `tool` **fallback switch** — **DECIDED: migrate `ComponentPalette` to `ToolRegistry.activate`**, then remove. Keystone: unblocks G1/G3/G7/G8.
- **G10** Hover highlight — no real hover-highlight owner exists (only a cosmetic tooltip).

## Highest-risk gaps for a delete step
G4 (Delete), G5/G6 (in-progress vertex drag + drawing preview), G7/G1 (legacy route/trace
editing & trace selection) — no tool or component currently claims them.

## Recommended closing order (per 2026-07-15 review)

Infrastructure debt first, then authoring experience. Do NOT delete
`InteractionController` until the Legacy Reachability Rule audit is done
(grep every `setTool(` / `legacySelectNode` / `legacySelectTrace` → usage →
tests → browser → coverage).


Grouping:
- **Infrastructure completion (architectural debt):** G2, G4, G6, G10.
- **Authoring experience (UX, not debt):** G5 (drag-rectangle room), Seam 3
  bridges are the last legacy removal.

1. **G2 / setActiveBuilding** — fold into `selectTool` or `SelectionManager`.
2. **G6 / drawing preview** — ✅ DONE: `InteractionController.updateDrawPreview` removed; draw/place tools own preview state and publish via `ToolContext.publishPreview`; `DrawingOverlay` is the sole `SRC.DRAWING` writer (Rendering Single-Writer Rule, ADR 006).
3. **G10 / hover tooltip** — ✅ DONE: cosmetic `Connection point` tooltip (and its `mouseenter`/`mouseleave` listeners + `tooltip` state) removed from `InteractionController`; `mouseleave` cursor-reset behavior kept. No real hover-highlight owner needed.
4. **G4 / Delete** — ✅ DONE: all delete entry points route through the unified `entity.delete` command (see ADR 006 + `entity-delete-handler.ts`); graph nodes are never deleted directly (ADR 005).
5. **Reachability audit + delete** unreachable `InteractionController` legacy code (the `switch(tool)` block, `legacySelectNode`/`legacySelectTrace` bridges, dead `legacy/RightPanel.tsx`, `StudioCanvas.legacy.tsx`, migrate `studio-store.test.ts` off `setTool('route')`).
6. **Seam 3** — `select-tool.ts:77` `legacySelectNode(...)` → `resolveGraphNodeSelection(...)`; delete `legacySelectNode`/`legacySelectTrace`.
7. **G5 / in-progress vertex drag** — own within the active draw tool (UX enhancement, last).
