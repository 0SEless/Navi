Three Modes — Three Tool Sets

The active mode changes which tools and panels are shown:

Campus Mode

Boundary tool, Building tool, Path tool, Gate tool, Search. Creates the outdoor campus shell.

Building Mode

Building info panel, floor management, color/image config. Exterior focus, activates on building click.

Floor Mode

Asset library, Canvas with floor plan, Properties panel. Rooms, hallways, stairs, elevators, QR, panoramas.

Improvements Over Current UI

  • Dark theme — map-focused work benefits from reduced glare
  • ASU brand colors — green #0F5132, gold #D1A11F, dark surface
  • Mode-aware tools — toolbar swaps per mode, context-sensitive
  • Floating floor strip — over the map, not in the toolbar
  • Publish workflow — Draft → Validate → Publish always visible in top bar
  • Dedicated asset section — QR, panoramas, access points listed in layers panel
  • Inline styles → Tailwind/shadcn — consistent, maintainable UI code
