# NAVI Project Requirements

Source: `C:\Users\Administrator\Downloads\NAVI_Project_Docs\PROJECT_REQUIREMENTS.md`

## User Roles

### End User

- Search destinations
- View campus map
- Follow navigation instructions
- Explore buildings
- View faculty and office information
- Scan QR codes
- Access indoor 360-degree navigation

### Admin

- Manage buildings
- Manage departments
- Manage faculty information
- Upload 360-degree images
- Create hotspots
- Record paths
- Manage routes
- View analytics

## Functional Requirements

- Authentication
- Navigation Engine
- Building Information Module
- Indoor Navigation Module
- QR Positioning Module
- Route Recording Module
- Admin Dashboard

## Non-Functional Requirements

- Mobile responsive
- Fast route calculation
- Offline cache support
- Secure authentication
- Scalable architecture
