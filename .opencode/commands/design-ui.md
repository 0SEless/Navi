## Workflow: UI/UX Design

### Step 1 — Design System
Load `ui-ux-pro-max`. Get comprehensive design recommendations: style, color palettes, typography, UX guidelines.

### Step 2 — Visual Design
Load `design`. Deep-dive into visual design patterns for the specific component or page.

### Step 3 — Styling Implementation
Load `ui-styling`. Get CSS/styling implementation guidance for the chosen design.

### Step 4 — Brand Consistency
Load `design-system`. Ensure brand consistency across all visual elements.
